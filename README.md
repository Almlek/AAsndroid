# سجل درجات الطلاب — مشروع أندرويد

تطبيق عربي يعمل دون إنترنت لإدارة أسماء الطلاب ودرجاتهم، مع البحث والإضافة والتعديل والحذف والاستيراد والتصدير CSV والطباعة. تُحفظ البيانات محليًا على الجهاز عبر localStorage داخل WebView.

## بناء APK

### تلقائيًا عبر GitHub Actions
1. أنشئ مستودع GitHub وارفع محتويات هذا المجلد إليه.
2. افتح تبويب **Actions**.
3. اختر **Build Android APK** ثم **Run workflow** (أو ادفع commit إلى main/master).
4. بعد اكتمال البناء، افتح تشغيل workflow ونزّل ملف Artifact باسم `سجل-درجات-الطلاب-APK`. يحتوي على `app-debug.apk`.

### بناء محليًا
يلزم تثبيت JDK 17 وAndroid SDK وGradle 8.9 أو إصدار متوافق، ثم من مجلد المشروع نفّذ:

```bash
gradle assembleDebug
```

المخرج: `app/build/outputs/apk/debug/app-debug.apk`.

## ملاحظات
- التطبيق لا يرسل البيانات إلى أي خادم.
- خذ نسخة احتياطية باستخدام تصدير CSV قبل مسح بيانات التطبيق أو تغيير الجهاز.
- الاستيراد مصمم لملفات CSV ذات أعمدة أسماء ودرجات؛ تختلف نتائج قراءة ملفات المدارس بحسب أسماء الأعمدة وبنية الملف.

## بيانات البداية
يتضمن التطبيق أسماء ونتائج الطلاب المقروءة من ملف CSV المرفق، ويعرض المجموع السنوي الموجود في العمود الإجمالي الأخير من الملف على أساس 1500 درجة. يمكن تعديل الدرجة النهائية عند الحاجة. احتفظ بنسخة احتياطية قبل استبدال البيانات.
